PYTRADE TEST CATALOG
====================

Purpose
-------
This catalog records every automated test suite, its responsibility, and the
command that runs it. Production source stays under src/ and app/; tests stay
under each package or app's test/ directory so that related behavior is easy
to find without mixing test code into production modules.

Commands
--------
pnpm test              Run all unit, service, HTTP, and tRPC tests.
pnpm test:watch        Run the same Vitest suites in watch mode.
pnpm test:unit         Run the fast Node-only project.
pnpm test:components   Run React component and server-page tests in jsdom.
pnpm test:integration  Run database and multi-module integration tests.
pnpm test:e2e          Run Playwright browser journeys against E2E_BASE_URL.
pnpm test:ci           Run unit, integration, then browser suites.

Individual packages also expose pnpm test (or pnpm test:unit for market-data)
to run only that package's unit tests.

Current automated coverage: 78 cases in 22 test files.

Conventions
===========

test/unit/         Pure logic: no database, network, filesystem, or live clock.
test/integration/  Real database or multiple modules; clean up all data.
test/fixtures/     Sanitized, static provider/import inputs only.
apps/*/test/http/  HTTP contract tests using Fastify inject rather than ports.
apps/*/test/auth/  Authentication-to-application-identity boundary tests.
apps/*/test/trpc/  Authenticated router tests with two-user ownership fixtures.
e2e/               Browser behavior only; keep it small and user-critical.

Vitest is the default TypeScript runner. React Testing Library is reserved for
component behavior, and Playwright is reserved for browser journeys.
