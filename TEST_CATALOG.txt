PYTRADE TEST CATALOG
====================

Purpose
-------
This catalog records every automated test suite, its responsibility, and the
command that runs it. Production source stays under src/ and app/; tests stay
under each package or app's test/ directory so that related behavior is easy
to find without mixing test code into production modules.

Commands
--------
pnpm test              Run all non-database Vitest tests: unit, service,
                       component/page, HTTP, authentication, and tRPC.
pnpm test:watch        Run the same Vitest suites in watch mode.
pnpm test:integration  Run database and multi-module integration tests. Locally,
                       it manages a disposable Docker PostgreSQL database; CI
                       supplies TEST_DATABASE_URL for its PostgreSQL service.
pnpm test:e2e          Run Playwright browser journeys against E2E_BASE_URL.

Individual packages also expose pnpm test (or pnpm test:unit for market-data)
to run only that package's unit tests.

Current automated coverage: 153 cases in 45 test files.

POSTGRESQL INTEGRATION TESTS
============================

These tests run against a disposable PostgreSQL database. Global setup drops
and recreates its public schema, then applies all checked-in migrations. The
test database name must contain "test"; remote databases require explicit
opt-in through ALLOW_REMOTE_TEST_DATABASE=true.

packages/db/test/integration/migrations-and-constraints.test.ts
  - Builds the complete schema from migration history.
  - Verifies user defaults and uniqueness constraints.
  - Verifies account deletion cascades to dependent records.

packages/db/test/integration/persistence.test.ts
  - Preserves an account's internal identity across SnapTrade upserts.
  - Keeps transaction, balance, and value-history upserts idempotent.
  - Rejects balance and value-history records for a different account.

apps/api/test/integration/application-user.test.ts
  - Resolves linked active users, rejects disabled users, and activates the
    exact pending application identity from Clerk metadata.
  - Leaves PostgreSQL unchanged for an unrelated Clerk identity.

apps/api/test/integration/http-api.test.ts

apps/api/test/integration/ownership-services.test.ts

Conventions
===========

test/unit/         Pure logic: no database, network, filesystem, or live clock.
test/integration/  Real database or multiple modules; clean up all data.
test/fixtures/     Sanitized, static provider/import inputs only.
apps/*/test/http/  HTTP contract tests using Fastify inject rather than ports.
apps/*/test/auth/  Authentication-to-application-identity boundary tests.
apps/*/test/trpc/  Authenticated router tests with two-user ownership fixtures.
e2e/               Browser behavior only; keep it small and user-critical.

Vitest is the default TypeScript runner. React Testing Library is reserved for
component behavior, and Playwright is reserved for browser journeys.
